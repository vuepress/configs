# @vuepress/oxlint-config

> Oxlint config for VuePress Team

**DO NOT use it in your own project if you don't know what it's for**

## Install

```sh
npm i -D @vuepress/oxlint-config oxlint
```

## Usage

Create `oxlint.config.ts`:

```ts
import { vuepress } from '@vuepress/oxlint-config'

export default vuepress()
```
